# Abhijith Murali — Portfolio

A responsive personal portfolio built with HTML, Tailwind CSS via CDN, Font Awesome, and plain JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. Tailwind CSS and Font Awesome load from their CDNs, so an internet connection is needed for the styling and icons.

## Project structure

```text
portfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── custom.css
│   └── js/
│       └── main.js
└── README.md
```

The page includes About, Skills, Education, Projects, and Contact sections, responsive navigation, project category filters, and a project-details modal. Academic percentages and CGPA scores are intentionally not included.
